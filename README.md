# 百人一首暗記アプリ

百人一首100首を、情景を味わいながら暗記するためのWebアプリ。

## 特徴

- 100首一覧 → 句を選択 → 詳細で「いつ・誰が / 情景 / 意味」を読む → 関連する句で次へ巡る、読み物としての導線
- 上の句クイズ・下の句クイズ（4択・即時フィードバック）
- 4軸の関連リンク: 同じ作者 / 同じテーマ / 同じ決まり字グループ / 同じ時代
- 縦書き表示（句本文）+ ルビ + アクセシブル読み上げ対応
- SEOフレンドリー（JSON-LD / sitemap / セマンティックHTML）

## スタック

- Next.js 15 App Router + TypeScript
- Tailwind CSS
- Cloudflare Pages（静的書き出し）

## ディレクトリ

- `docs/100.md` — 学習構成の元データ
- `docs/superpowers/specs/` — 設計仕様書
- `src/` — 実装（実装フェーズで作成）

## 出典

- `docs/100.md` 由来の解説（独自表現）
- 不足分は公知の百人一首データから補完・独自要約

詳細は `/about` ページで明示する予定。
